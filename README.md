# The Teichmüller Space of the Polygonable One-Holed Dilation Torus

**Fulin Zhong — September 2026**

We study polygonable dilation structures on the one-holed torus, and I wanna to give a more detailed type of pdf in there.

## Problem

Parametrize the marked dilation Teichmüller space of the polygonable one-holed torus.

## Main Result

The marked dilation Teichmüller space of the polygonable one-holed torus admits an explicit parametrization and is identified with

$$
\mathrm{SL}_2(\mathbb{R}) \times \mathbb{R}^2.
$$
